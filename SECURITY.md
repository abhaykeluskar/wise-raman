## Reporting a Vulnerability

The WiseRaman team takes the security of financial data very seriously. Because WiseRaman processes sensitive bank statements and transactions on local hardware, maintaining zero-leakage isolation is paramount.

If you discover a security vulnerability or potential data leak in WiseRaman:

1. **Do NOT open a public GitHub issue.**
2. Email the maintainer directly at **abhaykeluskar@gmail.com** with details.
3. Include:
   - A detailed description of the vulnerability.
   - Steps to reproduce the issue or a proof-of-concept.
   - Any potential impact on local data isolation.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to patch the issue before any public disclosure.
